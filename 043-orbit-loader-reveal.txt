Title: Lumen Relay Orbit Reveal

Description: A premium dark landing page for an invented interplanetary relay network that opens with an orbit loader. Satellites circle a small planet while a mono signal counter climbs. When it completes, the loader morphs into the page: the ring grows into the hero orbit, the core swells into the hero planet, and each satellite flies to its home in the logo, the call-to-action and the hero's moon. Copy, telemetry and feature panels then rise into place. The palette is midnight, peach and ice-blue, and the type pairs Avenir with a mono.

Visual techniques:
- requestAnimationFrame orbit loader with progress-driven speed and a bursty, time-bounded counter
- FLIP-style hand-off using getBoundingClientRect targets and Web Animations API geometry tweens
- Hidden target elements swapped in at hand-off for a seamless morph
- Staggered reveal via CSS custom-property delays (--i)
- Radial-gradient planet with inset shading, a soft-light band overlay and a halo
- Tiled radial-gradient starfield background
- Gradient-clipped italic headline accent
- Eased count-up telemetry and CSS hover-activated mini orbits
- Scroll lock during loading, a Replay control and prefers-reduced-motion fallbacks

Interaction model: The sequence plays automatically on load. After the reveal the page scrolls normally. Buttons and feature panels respond to hover with lifts, glows and orbiting icons, and all links and buttons show clear focus outlines. The "Replay sequence" button scrolls to the top, rebuilds the loader and runs the whole orbit-to-page morph again. It is guarded so it cannot overlap a run in progress.
