Title: torus.sh Amber Terminal

Description: A warm, retro computing piece where a glowing ASCII torus spins inside a carefully drawn terminal window. The amber phosphor, scanlines and vignette sell the illusion of a warm CRT tube, while a short boot sequence and a self-rewriting shell prompt give the scene a narrative. Every glyph is an actual lighting value calculated from 3D geometry, so the ring reads as a solid, shaded object made entirely of punctuation.

Visual techniques:
- Real-time 3D torus projection with z-buffer and Lambertian luminance mapped to character ramps
- Terminal chrome built in CSS with gradient title bar and traffic-light dots
- CRT scanlines and vignette with a repeating-linear-gradient and radial-gradient overlay
- Phosphor glow via layered text-shadow
- Theme swapping through CSS custom properties on body classes
- Staged boot log with timed line reveals and a steps() blinking caret
- Live fps counter

Interaction model:
Drag the donut to spin it by hand; releasing keeps the momentum, which then relaxes back to the default orbit. Buttons (or the space, r, t and f keys) hold the animation, cycle the shading ramp, switch the phosphor colour and change tempo, and the prompt line echoes each action as a shell command.
